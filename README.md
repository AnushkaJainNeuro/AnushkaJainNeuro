# Anushka Jain

Neuroscience @ UIC, class of 2030 · building toward the neurotech industry

I'm learning the signal-processing pipeline behind neural interfaces from the
ground up, starting with EEG: how to take raw brain recordings, clean them, and
pull real, interpretable results out of them. Long-term goal: work in neurotech,
building the systems that bridge brain and machine.

## What I've built

**[eeg-mne-analysis](https://github.com/AnushkaJainNeuro/eeg-mne-analysis)** —
four EEG analysis projects in Python / MNE-Python, working with real
electroencephalography data: signal filtering, power spectral density,
frequency-band analysis, and event-related potentials (ERPs). One result I'm
proud of — an ~80 ms difference between auditory and visual neural processing
times, measured from ERPs across stimulus conditions.
